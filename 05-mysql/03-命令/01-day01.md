# 01-day01

### 查看所有数据库

```sql
SHOW DATABASES;
```

###  创建数据库

```sql
CREATE DATABASE mydb;
```

### 使用（切换到）某个数据库

```sql
USE mydb;
```

### 查看表结构

```sql
DESCRIBE users;
-- 或简写
DESC users;
```

###  查看所有支持的存储引擎及其状态

```sql
SHOW ENGINES;
```

- `Support` 列说明：
  - `DEFAULT`：默认引擎（通常是 InnoDB）
  - `YES`：支持但非默认
  - `NO`：不支持
  - `DISABLED`：已禁用

### 查看当前数据库默认存储引擎

```sql
SHOW VARIABLES LIKE 'default_storage_engine';
```

### 查看所有配置参数（变量）

```sql
-- 查看所有全局变量
SHOW GLOBAL VARIABLES;

-- 查看所有会话变量
SHOW SESSION VARIABLES;
-- 或简写
SHOW VARIABLES;
```

数据量很大，通常配合 `LIKE` 过滤。

### 查看特定参数（常用示例）

```SQL
-- 查看端口
SHOW VARIABLES LIKE 'port';

-- 查看数据目录
SHOW VARIABLES LIKE 'datadir';

-- 查看最大连接数
SHOW VARIABLES LIKE 'max_connections';

-- 查看 InnoDB 相关参数
SHOW VARIABLES LIKE 'innodb%';

-- 查看字符集设置
SHOW VARIABLES LIKE 'character_set%';
SHOW VARIABLES LIKE 'collation%';
```
